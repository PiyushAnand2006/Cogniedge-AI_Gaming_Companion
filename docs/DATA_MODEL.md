# CogniEdge Local SQLite Data Model

Database File: `cogniedge/services/cogniedge.db`

---

## 1. Tables Overview

### `sessions`
- `id` (TEXT PK): Unique session identifier (e.g. `sess_a8f9c2d1`).
- `game_title` (TEXT): Name of active game (e.g. `Cyberpunk 2077`).
- `start_time` (REAL): Unix timestamp of session start.
- `end_time` (REAL): Unix timestamp of session conclusion.
- `duration_s` (REAL): Session duration in seconds.
- `avg_fps` (REAL): Average session framerate.
- `one_pct_low` (REAL): 1% Low FPS.
- `stutter_count` (INTEGER): Number of frame delivery anomalies.
- `kills` (INTEGER): Recorded combat eliminations.
- `deaths` (INTEGER): Recorded player deaths.
- `coach_rating` (TEXT): Evaluated session rating (`A+`, `A`, `B`, etc.).
- `summary` (TEXT): Structured session debrief generated by Qwen.
- `status` (TEXT): `ACTIVE` or `COMPLETED`.

### `player_patterns`
- `id` (TEXT PK): Pattern identifier (e.g. `pat_01`).
- `game_title` (TEXT): Associated game.
- `pattern_name` (TEXT): Descriptive pattern (e.g. `Low HP Over-Engagement`).
- `category` (TEXT): `TACTICAL`, `POSITIONING`, or `RESOURCE`.
- `description` (TEXT): Detailed behavioral context.
- `occurrences` (INTEGER): Times observed across sessions.
- `successful_corrections` (INTEGER): Times player acted to correct habit.
- `current_confidence` (REAL): Statistical confidence (0.0–1.0).
- `first_observed` (REAL) / `last_observed` (REAL): Timestamps.

### `recommendations` (Advice Effectiveness)
- `id` (TEXT PK): Recommendation identifier.
- `session_id` (TEXT FK): Linked session.
- `advice_text` (TEXT): Specific recommendation string.
- `category` (TEXT): `SURVIVAL`, `TACTICAL`, or `OPTIMIZATION`.
- `suggested_count` (INTEGER): Times suggested to player.
- `followed_count` (INTEGER): Times player complied.
- `success_outcomes` (INTEGER): Times compliance led to positive survival/framerate gain.
- `success_rate_pct` (REAL): Computed ROI success percentage.
- `last_suggested` (REAL): Timestamp.

### `session_events`
- `id` (TEXT PK): Event identifier.
- `session_id` (TEXT FK): Linked session.
- `timestamp` (REAL): Event time.
- `event_type` (TEXT): `HOSTILE_DETECTED`, `LOW_HP`, `DEATH`, `STUTTER_SPIKE`, `AI_ADVICE`, `OPTIMIZATION_APPLIED`.
- `description` (TEXT): Event summary.
- `metadata_json` (TEXT): Detailed payload attributes.
